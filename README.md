# IoT Vehicle Security Demo

Dashboard web sederhana untuk portofolio pemula Teknik Komputer. Project ini mendemonstrasikan antarmuka pemantauan status kendaraan, kontrol kunci simulasi, simulasi deteksi getaran, dan log kejadian.

> **Penting:** Ini hanya simulasi frontend. Project ini tidak terhubung ke ESP32, sensor, relay, aplikasi Android, atau kendaraan sungguhan.

## Fitur
- Tampilan status kendaraan: terkunci atau terbuka
- Status alarm siaga dan peringatan getaran
- Tombol kontrol simulasi
- Log aktivitas dengan waktu lokal
- Layout responsif untuk desktop dan ponsel
- Tidak membutuhkan instalasi package atau server

## Teknologi
- HTML
- CSS
- JavaScript (Vanilla)

## Cara menjalankan
1. Unduh atau clone repository ini.
2. Buka folder project.
3. Klik dua kali `index.html` atau buka file tersebut menggunakan browser.
4. Tekan tombol di bagian **Kontrol simulasi** untuk mencoba fitur.
